## 1. 引入：程序如何根据条件选择行为

成绩达到 60 分输出“及格”，否则输出“不及格”。这需要分支，而不是两条输出语句都执行。

```c
int score = 78;
if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

C 中条件为 0 表示假，非 0 表示真。`if` 后若只有一条语句可以省略花括号，但统一保留花括号更便于维护。不要在 `if (condition)` 后误加分号，那会使受控语句变成空语句。

## 2. if、else if 与悬空 else

区间判断适合按条件依次筛选：

```c
if (score < 0 || score > 100) {
    printf("成绩无效\n");
} else if (score >= 90) {
    printf("优秀\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

条件从上到下检查，进入一个分支后不再执行后面的分支。先检查 `>= 60` 再检查 `>= 90` 会让优秀分支失去机会，因此顺序要与范围包含关系一致。

`else` 总是与语法上最近的、尚未匹配的 `if` 结合，而不是与缩进对齐的 `if` 结合。用花括号明确嵌套层级，避免“悬空 else”。

## 3. 关系、逻辑和条件操作符

关系操作符为 `< <= > >= == !=`，结果是 `int` 类型的 0 或 1。数学写法 `0 <= x <= 100` 在 C 中不能表示区间，应该写成 `0 <= x && x <= 100`。

| 写法 | 条件成立的含义 |
| --- | --- |
| `a && b` | 两者都为真 |
| `a || b` | 至少一个为真 |
| `!a` | a 为假 |
| `cond ? x : y` | cond 为真取 x，否则取 y |

```c
int max = a > b ? a : b;
```

`&&` 和 `||` 有短路规则，且左操作数先求值：`&&` 左边假就不算右边，`||` 左边真就不算右边。可以用它保护后续操作：

```c
if (divisor != 0 && value / divisor > 3) {
    printf("商大于 3\n");
}
```

逻辑 `&&` 与按位 `&` 不同；后者不会提供这种短路保护。不要把重要状态更新偷偷放到可能被跳过的右操作数里。

### 案例：闰年

能被 400 整除，或者能被 4 整除但不能被 100 整除，才是闰年。

```c
int year = 2000;
int leap = (year % 400 == 0) ||
           (year % 4 == 0 && year % 100 != 0);
printf("%d 年%s闰年\n", year, leap ? "是" : "不是");
```

用 2000、1900、2024、2023 测试：分别为是、否、是、否。只测试普通年份很容易漏掉世纪年规则。

## 4. switch：离散选项的分支

```c
switch (choice) {
case 1:
    printf("开始游戏\n");
    break;
case 0:
    printf("退出\n");
    break;
default:
    printf("无效选择\n");
    break;
}
```

控制表达式应具有整数或枚举类型，`case` 标签是互不重复的整数常量表达式。`default` 处理未匹配情况。匹配后会继续向下执行，直到 `break` 或其他跳转，因此漏写 `break` 可能贯穿到下一个分支。多个 `case` 可共用一段逻辑，但应明确这是有意设计。

`switch` 擅长菜单、状态值；复杂范围和多个逻辑条件通常用 `if` 更自然。

## 5. 三种循环的执行过程

| 循环 | 检查条件的位置 | 典型场景 |
| --- | --- | --- |
| `while` | 执行循环体之前 | 次数未知，按条件继续 |
| `for` | 初始化后、每次循环体之前 | 次数或索引范围明确 |
| `do while` | 执行循环体之后 | 至少需要执行一次 |

```c
int sum = 0;
for (int i = 1; i <= 100; ++i) {
    sum += i;
}
printf("%d\n", sum); // 5050
```

`for` 顺序是：初始化一次 → 条件 → 循环体 → 更新 → 再检查条件。初始化中声明的 `i` 只在这个循环的作用域中可见。

`while` 适合不断缩小一个数：

```c
unsigned int n = 507;
while (n != 0) {
    printf("%u ", n % 10);
    n /= 10;
}
// 输出 7 0 5：取个位会得到逆序
```

要把 0 也当成一位数字，使用至少执行一次的结构：

```c
unsigned int n = 0;
int digits = 0;
do {
    ++digits;
    n /= 10;
} while (n != 0);
printf("位数：%d\n", digits); // 1
```

`do while` 结尾的分号是语法的一部分。`for (;;)` 是条件恒真的循环，必须依靠 `break`、`return` 等退出。

## 6. break 和 continue 的区别

- `break`：退出最近的一层循环或 `switch`。
- `continue`：跳过本轮循环体余下部分，进入下一轮的控制步骤。
- 在 `for` 中 `continue` 后仍执行更新表达式；在 `while` 中会直接回到条件判断。

```c
for (int i = 1; i <= 10; ++i) {
    if (i % 2 == 0) {
        continue;
    }
    printf("%d ", i); // 1 3 5 7 9
}
```

把这段代码机械改成 `while`，如果递增放在会被跳过的位置，就可能死循环。`break` 不会一次跳出所有嵌套循环。

## 7. 循环嵌套：找出 100 到 200 的素数

素数是大于 1 且只有 1 和自身两个正因数的整数。外层枚举候选数，内层尝试寻找因数；找到一个就可以停止试除。

```c
#include <stdio.h>

int main(void)
{
    for (int n = 100; n <= 200; ++n) {
        int prime = 1;
        for (int divisor = 2; divisor <= n / divisor; ++divisor) {
            if (n % divisor == 0) {
                prime = 0;
                break;
            }
        }
        if (prime) {
            printf("%d ", n);
        }
    }
    putchar('\n');
    return 0;
}
```

如果一个合数有大于平方根的因数，就必有一个小于等于平方根的配对因数，因此不必试到 `n - 1`。写成 `divisor <= n / divisor` 可避免 `divisor * divisor` 在更大输入上溢出。内层变量 `prime` 每次外层循环都要重新初始化。

## 8. goto 与结构化流程

`goto label;` 跳到同一函数内的标签。普通分支循环优先使用结构化语句；统一错误清理、多层循环退出有时可以用 `goto` 简化流程，但随意向前向后跳转会使状态难以跟踪。

## 9. 检查清单与练习

每个循环确认：初值、继续条件、推进动作和退出时的状态。重点测试“零次、一次、最后一次”。

练习：打印九九乘法表；求 1 到 n 的阶乘和；输出一个非负整数的逆序各位。尝试先写流程，再写代码，最后逐轮记录变量变化，不要一开始就追求最短表达式。
