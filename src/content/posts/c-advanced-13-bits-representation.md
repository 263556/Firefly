## 1. 引入：用一个整数保存多个开关

文件有读、写、执行三种权限，每种都是开或关。与其使用三个变量，可以给每种权限分配一个二进制位：第 0 位读、第 1 位写、第 2 位执行。一个整数就能组合多个独立状态。

```c
#include <stdio.h>

enum Permission {
    PERM_READ = 1u << 0,
    PERM_WRITE = 1u << 1,
    PERM_EXEC = 1u << 2
};

int main(void)
{
    unsigned int flags = PERM_READ | PERM_WRITE;
    flags &= ~((unsigned int)PERM_WRITE); // 清除写权限
    flags ^= PERM_EXEC;                   // 切换执行权限

    printf("read=%d write=%d exec=%d\n",
           (flags & PERM_READ) != 0,
           (flags & PERM_WRITE) != 0,
           (flags & PERM_EXEC) != 0);
    return 0;
}
```

结果为 `read=1 write=0 exec=1`。本篇要回答的就是：这些二进制位从哪里来，又如何可靠地操作它们？

## 2. 数值与进制表示

同一个数值可以有不同表示，进制改变的是写法，不是大小。二进制每位权重为 2 的幂，八进制每位权重为 8 的幂，十六进制每位权重为 16 的幂。

```text
二进制 1101 = 1×8 + 1×4 + 0×2 + 1×1 = 十进制 13
十六进制 6B = 6×16 + 11 = 十进制 107
八进制 153 = 1×64 + 5×8 + 3 = 十进制 107
```

十进制转二进制：反复除以 2，记录余数，最后倒序排列。例如 13 的余数依次为 1、0、1、1，反读得到 1101。

二进制转八进制，从低位每 3 位分组；转十六进制，每 4 位分组，因为 `8 = 2³`、`16 = 2⁴`。

```text
01101011 = 001 101 011 = 153（八进制）
01101011 = 0110 1011 = 6B（十六进制）
```

C17 中 `107` 是十进制，`0153` 是八进制，`0x6B` 是十六进制。前导 0 不是装饰，`010` 实际是十进制 8。`0b` 二进制字面量在 C23 纳入标准，较旧标准模式中不要依赖编译器扩展。

## 3. 原码、反码与补码的推导

以教学用的 **8 位有符号补码模型** 表示 -5：

| 表示 | 位序列 | 推导 |
| --- | --- | --- |
| 原码 | `10000101` | 最高位表示负号，其余是 5 |
| 反码 | `11111010` | 原码符号位不变，其余取反 |
| 补码 | `11111011` | 反码加 1 |

补码可以让减法用加上相反数来表达。例如 8 位下 `5 + (-5)` 的位模式相加得到低 8 位全 0，最高进位舍弃。补码只有一个零，8 位范围为 -128..127；最小负数没有同宽的正数对应值，因此对最小负数直接取负需要特别小心。

这张表用于理解常见机器的表示。C17 仍允许其他有符号表示，C23 才要求补码；即便机器使用补码，**有符号整数溢出在 C 中仍是未定义行为**。不能从硬件会丢弃高位，推出 `INT_MAX + 1` 在 C 程序中一定合法回绕。

无符号算术按模数回绕，不需要符号位；适合位模式处理。`printf("%d", x)` 输出的是按 `int` 解释后的数值，不是输出“内存原码”；原码和补码是理解表示的模型，不是输出函数切换的格式。

## 4. 字节序：改变排列，不改变数值

假设一个 32 位无符号整数值为 `0x11223344`，且每字节 8 位：

| 地址从低到高 | 第 1 字节 | 第 2 字节 | 第 3 字节 | 第 4 字节 |
| --- | --- | --- | --- | --- |
| 小端 | `44` | `33` | `22` | `11` |
| 大端 | `11` | `22` | `33` | `44` |

小端把低有效字节放低地址，大端把高有效字节放低地址。讨论的是**字节之间的顺序**，不是把每个字节内部的比特也反过来。

可通过 `unsigned char *` 合法观察对象表示：

```c
#include <stdio.h>
#include <stdint.h>
#include <limits.h>

int main(void)
{
    uint32_t value = UINT32_C(0x11223344);
    const unsigned char *bytes = (const unsigned char *)&value;
    printf("CHAR_BIT=%d, bytes:", CHAR_BIT);
    for (size_t i = 0; i < sizeof value; ++i) {
        printf(" %02X", (unsigned int)bytes[i]);
    }
    putchar('\n');
    return 0;
}
```

此例要求实现提供 `uint32_t`。常见 8 位字节小端平台输出 `44 33 22 11`。网络协议和文件格式应明确字节序，不能直接发送本机整数内存后假定所有接收方布局一致。网络字节序通常指大端，但具体协议仍以自己的规定为准。

## 5. 浮点表示的初步认识

课件将浮点存储列作加餐。常见 IEEE 754 binary32 用 1 位符号、8 位阶码、23 位尾数表示；正常值可以写为 `(-1)^s × (1.f) × 2^(E-127)`。此外还有零、非规格化值、无穷和 NaN 等特殊编码。

`0.1` 的二进制小数无限循环，有限尾数只能近似保存，因此浮点比较和累计误差不能按十进制直觉处理。C 不保证所有平台的 `float` 都是这种布局，也不应通过 `*(int *)&f` 强行读取位模式；需要观察时用 `memcpy` 到适当对象或逐字节查看。

## 6. 移位规则与类型提升

`x << n` 左移，`x >> n` 右移。移位次数必须非负，并小于左操作数**整型提升之后**的类型宽度。负位移、移位次数等于或超过宽度，都是未定义行为。

无符号左移按模数保留可表示的低位；无符号右移高位补 0。C17 对负有符号数右移采用实现定义行为，有符号左移还受非负与结果可表示等条件限制。位操作优先使用无符号类型，可以避开大量含糊边界。

```c
unsigned int x = 13u; // 二进制 1101
unsigned int a = x << 1; // 26
unsigned int b = x >> 1; // 6
```

表达式不会自动修改 x，`x <<= 1` 才会保存结果。`1 << k` 的左边是有符号 `int`，更适合写成 `1u << k`，并先保证 k 在有效范围内。`unsigned char` 也会先提升为 `int`，并非只在 8 位内运算。

## 7. 四种位运算与掩码

| 运算 | 对应位的结果 | 常见用途 |
| --- | --- | --- |
| `a & b` | 两者为 1 才为 1 | 读取或保留部分位 |
| `a \| b` | 至少一个为 1 就为 1 | 设置位 |
| `a ^ b` | 不同为 1 | 切换位、异或归并 |
| `~a` | 每位取反 | 配合掩码清除位 |

对第 k 位，掩码为 `1u << k`：置位 `x |= mask`，清零 `x &= ~mask`，翻转 `x ^= mask`，检查 `(x & mask) != 0`。

逻辑 `&&`、`||` 把操作数解释为真假并短路；位运算逐位处理整数，没有同样的短路规则。检查多个权限“全部具备”应写 `(flags & mask) == mask`，而不只是检查非零。

## 8. 案例：统计二进制中 1 的个数

`x & (x - 1)` 每次清除最低位的 1：`1100 & 1011 = 1000`。有几个 1 就循环几次。

```c
#include <stdio.h>

unsigned int count_ones(unsigned int x)
{
    unsigned int count = 0;
    while (x != 0) {
        x &= x - 1u;
        ++count;
    }
    return count;
}

int main(void)
{
    printf("%u %u %u\n", count_ones(0), count_ones(13), count_ones(255));
    return 0;
}
```

输出 `0 3 8`。采用无符号数，避免负有符号数在 `x - 1` 等步骤溢出。判断正整数是否为 2 的幂可用 `x != 0 && (x & (x - 1u)) == 0`，不能漏掉排除 0。

## 9. 异或交换与练习

正确性质是 `a ^ a == 0`、`a ^ 0 == a`，且异或满足交换律、结合律。它能推导三步交换，但若两个指针实际指向同一对象，异或交换会把值清零。实际代码优先用临时变量交换，表达意图更清楚，也便于编译器优化。

练习：实现第 k 位的设置与清除，检查边界 k；写函数计算两个无符号整数中不同位的数量（提示：先异或再计数）；观察同一整数的十进制输出与逐字节输出，区分数值与表示。
